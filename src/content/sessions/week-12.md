## Reading the whole table

Instead of treating each shot as an isolated decision, read the full
layout: which balls are available, what order makes position easiest, and
where the difficult balls are relative to the easier ones.

## One repeatable sequence

Read → Plan → Aim → Set up → Execute → Control → Position → Reassess.

This is the same sequence, in essence, that's run through the whole
course — the pre-shot routine from Weeks 2–4, cue-ball control from Weeks
5–7, and position play from Weeks 8–10 — now applied continuously across
a full run rather than to one shot at a time.

## Using what you've built

Across a run, different tools apply at different moments — an exact
finishing point for a tight next shot, a workable zone when precision
isn't required, a planned route when the shot after next depends on it,
and a safety decision when attacking isn't the best option. None of these
replace the others; a full run usually calls on all of them.

## Three shots ahead, in practice

By this point, "three shots ahead" isn't a phrase to remember — it's a
habit applied while reading any layout: this shot, the one it sets up, and
the one after that. Planning three shots does not mean refusing to change
the plan. A good player reassesses and updates the plan after every
result, not only when something goes wrong.
