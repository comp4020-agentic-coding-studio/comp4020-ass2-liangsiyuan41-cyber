## The brief

> An online, visual, multiple-choice assessment. Using diagrams and labelled
> placeholders, it checks table understanding, pre-shot setup recognition,
> straight-shot diagnosis, and object-ball path / contact-point reasoning.

This assessment only draws on Weeks 1 to 4. It does not test cue-ball
control, spin, or position play, since none of that has been taught yet at
this point in the course.

## What you submit

Completed online, individually, within the assessment window.
