# Know the Game

Week 1 — Opening lecture

---

{/* _class: impact */}

## Cue ball → object ball → pocket → rail

Identify these four things before every shot.

---

## Beginner course rules

- A simple, consistent set of turn-taking and foul rules
- Enough to play safely and fairly together
- A starting point for learning the game — not competition regulations

---

## Etiquette and safety

- Handle the cue and table safely and respectfully
- Wait until the table is clear before shooting
- Respect the equipment and other players

---

## Before every shot, ask

1. Where's the cue ball?
2. Which object ball?
3. Which pocket?
4. Where's the rail?
